# Shura

MUGUNG은 한국 설화의 영웅들과 함께 15분을 버티는 2D 협동 생존 액션 게임입니다.

## 게임 시작

1. Unity에서 `Assets/_Project/Scenes/MainMenu.unity`를 엽니다.
2. Play 버튼을 누릅니다.
3. 싱글 플레이는 캐릭터 선택 후 바로 시작합니다.
4. 멀티 플레이는 한 명이 방을 만들고 참가 코드를 친구에게 전달합니다.
5. 두 명이 입장하면 호스트가 게임을 시작합니다.

멀티플레이 입장 화면은 작업 상태를 색상으로 안내합니다. 초록색은 준비·완료, 붉은색은 실패·오류를 의미합니다.
영웅 선택 로비에서는 화면 상단의 참가 코드와 접속 인원을 확인하고, 두 명이 준비되면 호스트가 게임을 시작합니다.

## 조작

- 이동: `WASD` 또는 방향키
- 기본 공격·일반 스킬: 자동 발동
- 캐릭터 필살기: `R`
- 게임 메뉴: `ESC`
- 조작 도움말: `F1`

메인 메뉴의 `게임 방법`에서 목표와 핵심 조작을 확인할 수 있습니다. `설정`에서는 배경 음악·효과음 음량과 전체 화면 여부를 변경할 수 있으며 다음 실행에도 유지됩니다.

## 개발 환경

- Unity 버전: `6000.3.20f1`
- 주 개발 플랫폼: Windows
- 해커톤 제출 플랫폼: Web

## 브랜치 전략

- `main`: 안정적인 배포 및 제출 버전을 관리합니다.
- `develop`: 다음 배포를 위한 기능을 통합하고 검증합니다.
- `feat/*`: 개별 기능을 개발합니다. 완료 후 `develop`에 병합합니다.

## Unity Hub에서 실행하기

1. Unity Hub를 실행합니다.
2. **Add** 또는 **Open**을 선택합니다.
3. 이 저장소의 최상단 폴더를 선택합니다.
4. Unity Editor `6000.3.20f1`이 설치되어 있는지 확인합니다.
5. 해당 버전으로 프로젝트를 엽니다.
6. 최초 실행 시 패키지 임포트와 에셋 데이터베이스 생성이 끝날 때까지 기다립니다.
