## 3. 속성 조합표 — 진행 중 (미완)

### 확정된 규칙

- 서로 다른 플레이어의 속성 조합만 연계 발동
- 반응 없는 조합은 무반응일 뿐, 디버프는 없음

### 효과 초안까지 나온 조합 (7개, 아직 채택 확정 아님)

| 조합 | 반응명 초안 | 효과 초안 |
|---|---|---|
| 독+물 | 오염 확산 | 주변 적에게 독(지속 피해) 전이 |
| 독+번개 | 신경 마비 | 짧은 스턴 + 피해 |
| 독+얼음 | 부식 동결 | 슬로우 + 받는 피해 증가 |
| 독+흙 | 독늪 | 지속 피해 + 감속 장판 |
| 독+바람 | 독안개 | 퍼지는 독구름 장판 |
| 독+불 | 화독 폭발 | 즉시 폭발 + 독 피해 증폭 |
| 물+번개 | 감전 | 주변 적 연쇄 전이 피해 |

### 이전 초안에서 나온 추가 후보 (미확정)

물+얼음=빙결(CC), 불+바람=화염 폭풍, 얼음+흙=분쇄, 불+흙=용암 장판, 번개+흙=자기장(끌어당김), 번개+바람=뇌풍(확산), 물+흙=늪(감속)

### 아직 정의 안 된 조합

물+바람, 물+불, 번개+얼음, 번개+불, 얼음+바람, 얼음+불, 흙+바람 (+ 위 후보들의 채택 여부)
