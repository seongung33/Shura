## 1. 결과 표기

- **통과:** 명시된 커밋·빌드·환경에서 절차와 기대 결과를 확인했다.
- **부분:** 흐름 일부만 확인했거나 임시 값·프리팹을 사용했다.
- **과거 통과:** 기능 브랜치나 로컬 단독 테스트 기록은 있지만 현재 통합본 회귀가 필요하다.
- **미실행:** 실행 증거가 없다.
- **차단:** 선행 구현이 없어 실행할 수 없다.

구현 존재만으로 통과 처리하지 않는다. 네트워크 기능은 두 인스턴스의 결과를 비교해야 한다.

## 9. 새 Clone·제출 후보 검증

1. 깨끗한 폴더에 저장소를 Clone한다.
2. 제출 후보 커밋 또는 태그를 Checkout한다.
3. Unity `6000.3.20f1`로 열고 Library 재생성을 기다린다.
4. Console 오류와 Missing Script·Missing Prefab을 확인한다.
5. `MainMenu`에서 시작해 `MultiPlayerEntry → MultiPlayerLobby → Main`을 Editor·실행 파일 또는 두 실행 파일로 2인 회귀한다.
6. `NetworkTest`는 레거시 비교가 필요할 때만 별도로 실행한다.
7. Windows와 Web 빌드를 생성한다.
8. Web 링크를 시크릿 창과 다른 기기에서 확인한다.
9. 결과를 이 문서와 제출 체크리스트에 기록한다.

현재 선행 정리:

- Git LFS 임시 폴더 권한 오류와 주몽 PNG 상태 확인
- 2인 시작 최소 인원, 캐릭터 선택 전투 적용, 결과 후 정식 복귀 경로 정리
- 최신 통합 Windows 실행 파일의 산출 위치와 커밋 기록
- Web 빌드 경로 확정

## 10. 제출 차단 버그

- 방 생성·참가 또는 게임 시작 불가
- 한 판을 끝낼 수 없음
- 두 화면의 핵심 체력·승패 상태 불일치
- 연계 효과 미발동
- Web 링크 미접속
- 반복적인 멈춤·연결 종료·Console 오류
- 조작 방법을 알 수 없음
