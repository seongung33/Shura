> 마지막 증거 정리: **2026-08-03 KST**

## 1. 결과 표기

- **통과:** 명시된 커밋·빌드·환경에서 절차와 기대 결과를 확인했다.
- **부분:** 흐름 일부만 확인했거나 임시 값·프리팹을 사용했다.
- **과거 통과:** 기능 브랜치나 로컬 단독 테스트 기록은 있지만 현재 통합본 회귀가 필요하다.
- **미실행:** 실행 증거가 없다.
- **차단:** 선행 구현이 없어 실행할 수 없다.

구현 존재만으로 통과 처리하지 않는다. 네트워크 기능은 두 인스턴스의 결과를 비교해야 한다.

## 8. 새 Clone·제출 후보 검증

1. 깨끗한 폴더에 저장소를 Clone한다.
2. 제출 후보 커밋 또는 태그를 Checkout한다.
3. Unity `6000.3.20f1`로 열고 Library 재생성을 기다린다.
4. Console 오류와 Missing Script·Missing Prefab을 확인한다.
5. `NetworkTest`에서 Editor·실행 파일 또는 두 실행 파일로 2인 회귀를 수행한다.
6. Windows와 Web 빌드를 생성한다.
7. Web 링크를 시크릿 창과 다른 기기에서 확인한다.
8. 결과를 이 문서와 제출 체크리스트에 기록한다.

현재 선행 정리:

- 장산범과 주몽 SkillData 폴더 이동을 커밋
- `StageTest`와 `Main`의 보스·웨이브 설정 의도 명시
- 최신 통합 Windows 실행 파일의 산출 위치와 커밋 기록
- Web 빌드 경로 확정
