# Shura 테스트 계획

## 1. 테스트 원칙

- “내 PC에서 한 번 실행됨”을 완료로 보지 않는다.
- 기능 테스트, 두 PC 테스트, 새 Clone 테스트, Web 링크 테스트를 분리한다.
- 버그는 재현 순서와 기대·실제 결과를 함께 기록한다.
- 8월 7일부터는 새 기능보다 회귀 테스트를 우선한다.

## 6. 새 Clone 검증

팀원의 기존 프로젝트가 아닌 새 폴더에서 확인한다.

1. 저장소를 Clone한다.
2. `develop` 또는 제출 시 `main`을 Checkout한다.
3. README에 적힌 정확한 Unity 버전으로 연다.
4. Unity가 `Library`를 새로 생성하도록 기다린다.
5. Console 오류를 확인한다.
6. Main 씬을 실행한다.
7. Windows 또는 Web 빌드를 생성한다.

## 8. 제출 차단 버그

다음 문제는 다른 작업보다 먼저 해결한다.

- 게임을 시작할 수 없음
- Web 링크가 열리지 않음
- 두 플레이어가 방에 들어갈 수 없음
- 한 판을 끝낼 수 없음
- 연계 효과가 발동하지 않음
- 진행 중 반복적으로 멈춤
- 조작 방법을 알 수 없음
- Console 오류가 지속적으로 쌓임
