# NAN 2026 제출 체크리스트

## 1. 일정

- 사전 과제 제출 마감: **2026년 8월 10일**
- 본선 예정: **2026년 9월 4일~6일**
- 공식 행사 페이지: <https://nan2026.nhn.com/>

제출은 마감 직전이 아니라 8월 10일 여유 있는 시간에 완료하고 제출 결과를 캡처한다.

제출 항목과 탈락 조건은 최종 신청 폼 또는 공식 안내 원문을 제출 직전에 다시 대조한다. 이 문서는 팀 내부 준비 체크리스트이며 공식 약관을 대신하지 않는다.

## 4. 저장소 제출 전 점검

- [ ] 기본 브랜치가 `main`
- [ ] `master` 제거
- [ ] 제출 커밋이 `main`에 병합됨
- [ ] 제출 시점 Git 태그 생성
- [ ] README 링크가 모두 작동
- [ ] 게임 실행 방법이 초보자도 이해 가능
- [ ] 사용하지 않는 대용량 파일 제거
- [ ] 비밀키와 개인정보가 없음
- [ ] 외부 에셋 출처 누락 없음
- [ ] 커밋 기록을 Squash 또는 재작성하여 없애지 않음

현재 확인된 저장소 위험:

- `main`은 초기 프로젝트 수준이며 제출 기능이 병합되지 않았다.
- 현재 `feat/map_generate`와 `origin/develop`이 서로 다른 기능을 포함한다.
- HUD 수정 브랜치와 로컬 아이템 작업까지 통합한 뒤 새 Clone 검증이 필요하다.
- Build Settings에는 `NetworkTest`만 활성화되어 있다.

권장 최종 태그:

```bash
git tag -a hackathon-submission-v1.0 -m "NAN 2026 사전 과제 제출본"
git push origin hackathon-submission-v1.0
```
