# NAN 2026 제출 체크리스트

## 1. 일정

- 사전 과제 제출 마감: **2026년 8월 10일**
- 본선 예정: **2026년 9월 4일~6일**
- 공식 행사 페이지: <https://nan2026.nhn.com/>

제출은 마감 직전이 아니라 8월 10일 여유 있는 시간에 완료하고 제출 결과를 캡처한다.

## 2. 필수 제출물

아래 항목 중 하나라도 누락되면 심사 대상에서 제외될 수 있다.

### 1) 플레이 가능한 빌드 및 전체 소스 코드

- [ ] GitHub 저장소 링크
- [ ] 저장소 공개 상태 또는 심사 계정 접근 권한
- [ ] Web 링크 클릭 후 브라우저 실행
- [ ] 별도 유료 라이선스 없이 실행
- [ ] 전체 Unity 소스 포함
- [ ] 커밋 기록 유지
- [ ] `README.md`에 Unity 버전과 실행 방법 작성
- [ ] `Library`, `Temp`, `Logs`, `UserSettings` 제외
- [ ] 다른 PC에서 새로 Clone하여 실행 확인
- [ ] 심사 종료까지 링크 유지

비공개 저장소를 사용해야 하는 경우 심사 계정 초대 여부를 다시 확인한다.

### 2) 플레이 동영상

- [ ] 30~60초 길이
- [ ] 실제 플레이 화면 중심
- [ ] 조작·합성으로 게임 플레이를 왜곡하지 않음
- [ ] 핵심 연계 효과가 영상 안에 등장
- [ ] 시작·전투·연계·결과가 짧게 연결됨
- [ ] YouTube 공개 또는 일부 공개
- [ ] 로그아웃 상태에서 링크 재생 확인
- [ ] 심사 종료까지 링크 유지

권장 영상 구성:

```text
0~5초: 제목과 한 줄 소개
5~15초: 2인 이동과 기본 전투
15~35초: 스킬 연계 2개
35~50초: 적 무리 또는 보스
50~60초: 결과와 플레이 링크
```

### 3) 게임 소개 및 설명 PDF

- [ ] 게임 제목과 한 줄 소개
- [ ] 게임 개요와 차별점
- [ ] 목표
- [ ] 조작 방법
- [ ] 종료·승리·패배 조건
- [ ] 설치 또는 실행 방법
- [ ] 플레이 링크
- [ ] 플레이 영상 링크
- [ ] 팀명과 팀원
- [ ] PDF를 다른 기기에서 열어봄

### 4) AI 활용 기술 PDF

- [ ] 사용한 AI 도구
- [ ] AI 활용 구조
- [ ] 대표 프롬프트와 지시 사항
- [ ] AI 생성 결과
- [ ] 사람이 검토·수정한 내용
- [ ] 실제 프로젝트 적용 위치
- [ ] 외부 에셋 출처와 라이선스
- [ ] 오픈소스 패키지와 라이선스
- [ ] AI 사용의 한계와 검증 방법

### 5) 팀원 역할 기술 PDF

- [ ] 팀원 3명의 이름
- [ ] 각 팀원의 담당 역할
- [ ] 실제 구현한 영역
- [ ] 공동 개발 영역
- [ ] 협업과 분업 방식
- [ ] Git 커밋 또는 결과물과 역할이 일치

## 3. 저장소 제출 전 점검

- [ ] 기본 브랜치가 `main`
- [ ] `master` 제거
- [ ] 제출 커밋이 `main`에 병합됨
- [ ] 제출 시점 Git 태그 생성
- [ ] README 링크가 모두 작동
- [ ] 게임 실행 방법이 초보자도 이해 가능
- [ ] 사용하지 않는 대용량 파일 제거
- [ ] 비밀키와 개인정보가 없음
- [ ] 외부 에셋 출처 누락 없음
- [ ] 커밋 기록을 Squash 또는 재작성하여 없애지 않음

권장 최종 태그:

```bash
git tag -a hackathon-submission-v1.0 -m "NAN 2026 사전 과제 제출본"
git push origin hackathon-submission-v1.0
```
