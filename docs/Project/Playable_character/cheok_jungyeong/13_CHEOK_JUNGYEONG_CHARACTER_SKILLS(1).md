## 0. 복원 근거와 우선순위

이번 갱신에서 확인된 가장 최신의 척준경 구현 프롬프트 핵심은 다음과 같다.

- 캐릭터 역할: **근접 돌파형**
- 기본공격: **철혈참**, 전방 부채꼴 근접 공격
- 일반 스킬: **파진 · 회천참 · 파성참 · 검풍 · 혈로** 총 5종
- 각 일반 스킬: **Lv1~Lv5 성장**
- 한 판에서 일반 스킬을 **최대 3개** 보유하고, 이미 가진 스킬을 다시 선택하면 레벨업
- 당시 실제 연계 구현 범위에 맞춰 속성 후보를 **Water / Lightning / Ice / Earth**로 제한
- R 필살기: **일기당천**
- `일기당천`: **약 6초 동안 폭주 상태**, **쿨타임 약 60초**
- Git 작업 흐름: `develop` 최신화 → 새 feature branch → 구현/검증 → commit → push → PR로 `develop` 병합

이 항목이 이전 대화에서 나온 초안과 충돌하면 이 절을 우선한다. 특히 이전 복원본에 적었던 “일기당천 = 전방 단발 필살 참격” 해석은 **폐기**한다.

## 1. 캐릭터 개요

### 척준경

- 모티프: **고려시대 무신 척준경**
- 전투 역할: **근접 돌파형 / 근접 광역 딜러 / 전열 유지형**
- 전투 이미지: 적진에 직접 파고들어 다수의 적을 검으로 쓸어버리는 무쌍형 전사
- 핵심 키워드: **돌파, 광역 베기, 회전 베기, 방어 파괴, 강한 한 방, 일기당천**
- 무기 방향: **대형 사이버 장검 / 철혈대검 계열**
- 주몽과의 역할 구분:
  - 주몽: 원거리 투사체·장판 중심
  - 척준경: 근거리 진입·전방 압박·주변 광역 처치 중심

### 초기 상세안에서 언급된 자원

- `철의 기세`라는 핵심 자원이 한 차례 상세 설계안에 포함됐다.
- 이후 8월 9일 구현 프롬프트에서는 이 자원이 핵심 구현 조건으로 다시 확인되지 않았다.
- 따라서 현재는 **보류/확장 후보**로 취급한다.

## 2. 척준경 스킬 구성

대화에서 반복적으로 확인된 척준경의 스킬 구성은 다음과 같다.

| 구분 | 스킬 | 역할 |
|---|---|---|
| 기본공격 | **철혈참** | 전방 부채꼴 근접 검격 |
| 일반 스킬 1 | **파진(破陣)** | 적진을 직접 가르는 돌파기 |
| 일반 스킬 2 | **회천참** | 플레이어 중심 360도 광역 회전 베기 |
| 일반 스킬 3 | **파성참(破城斬)** | 전방을 붕괴시키는 강한 파괴형 참격 |
| 일반 스킬 4 | **검풍** | 관통하는 전방 검기 투사체 |
| 일반 스킬 5 | **혈로** | 이동하며 주변을 지속적으로 베는 강화 상태 |
| R 필살기 | **일기당천** | 약 6초간 이어지는 폭주형 전투 강화 필살기 |

> 2026-08-10 아이콘 논의에서는 기본공격이 **`철검 연격`**이라는 이름으로도 표현됐다. 해당 시점의 설명은 “부채꼴 범위 베기 + 적중 시 확률적으로 연속 추가 베기”였다. `철혈참`의 개명인지 별도 시각 표현명인지는 대화에서 최종 정리되지 않았으므로, 본 문서에서는 앞서 반복적으로 사용된 **철혈참**을 기준명으로 유지하고 `철검 연격`은 명칭 변경 후보로 기록한다.

## 3. 공통 습득·성장 규칙

### 한 판의 일반 스킬 보유

- 척준경의 일반 스킬 후보는 총 **5개**다.
- 한 판에서 서로 다른 일반 스킬은 **최대 3개**까지 보유한다.
- 아직 없는 스킬을 선택하면 **Lv1로 신규 습득**한다.
- 이미 가진 스킬을 다시 선택하면 **Lv1 → Lv2 → Lv3 → Lv4 → Lv5**로 강화한다.
- **Lv5가 최대 레벨**이다.
- Lv5가 된 스킬은 이후 선택 후보에서 제외한다.

### 속성

- 일반 스킬은 습득 시 속성 하나를 부여받고, 같은 스킬을 강화해도 **처음 받은 속성을 유지**한다.
- 8월 9일 리모트 구현 범위에서는 현재 실제 연계가 구현된 속성에 맞춰 후보를 다음 4종으로 제한하는 방향을 사용했다.
  - `Water`
  - `Lightning`
  - `Ice`
  - `Earth`
- 이후 7속성 전체가 안정화되면 Poison/Fire/Wind까지 다시 확장할 수 있다.

### 구현 공통 원칙

- 실제 피해는 서버가 최종 판정한다.
- 피해 전달은 기존 프로젝트 계약인 `IDamageable.TakeDamage`를 유지한다.
- 기존 시스템으로 구현 가능한 경우 새 병렬 시스템을 만들지 않는다.
- 속성 적용은 기존 원소/연계 판정 흐름을 재사용한다.

# 4. 기본공격 — 철혈참

## 기본 콘셉트

- 척준경 전방을 베는 **부채꼴 근접 검격**.
- 다수의 적에게 동시에 닿는 근접 기본공격으로 설계됐다.
- 척준경의 “적 무리 속에 들어가 직접 쓸어버리는” 전투 감각의 출발점이다.

## 명칭 변경 후보 — 철검 연격

8월 10일 스킬 아이콘 논의에서는 기본공격을 `철검 연격`으로 표현하면서 다음 특징이 언급됐다.

- 부채꼴 범위 베기
- 적중 시 확률적으로 **연속 2회 추가 베기**
- 시각적으로 첫 검격과 겹치는 추가 검 궤적
- 3연격을 암시하는 붉은 잔상

## Lv1~Lv5

- 별도의 Lv별 확정 수치는 과거 대화가 존재했다는 흔적은 확인되지만, 현재 검색 가능한 대화 조각에서는 원문 전체를 복원하지 못했다.
- 따라서 **구체 수치는 임의 작성하지 않는다.**

# 5. 일반 스킬 — 파진(破陣)

## 핵심 콘셉트

> **적진을 가른다.**

- 이름 뜻 그대로 적의 진형을 깨뜨리는 척준경의 대표 **근접 돌파기**.
- 한자 타이틀 `破陣`을 크게 표시하고 작은 한글 부제로 `파진`을 두는 UI 방향도 논의됐다.
- “파진 · 돌진”처럼 돌파 이미지를 직접 강조하는 표현이 제안됐다.

## 현재 복원 가능한 확정 범위

- 근접 돌파형 기술
- 적진을 가르는 공격
- 척준경의 핵심 정체성을 보여주는 스킬

## Lv1~Lv5

- 8월 9일 대화에서 파진을 별도로 구현하려고 다시 논의했으며, 당시 세부 형태를
  - 이동하면서 베는 돌진형 / 제자리 공격
  - 부채꼴 / 직사각형 / 원형
  - 단일 강타 / 광역 피해
  로 최종 선택하려 했다.
- 그러나 그 선택에 대한 사용자 답변은 현재 검색 가능한 기록에서 복원되지 않았다.
- 따라서 **Lv별 세부 수치와 최종 판정 형태는 미확인**으로 남긴다.

# 6. 일반 스킬 — 회천참

플레이어를 중심으로 검을 크게 회전시켜 주변 적을 베는 **360도 광역기**.

| 레벨 | 효과 |
|---|---|
| **Lv1** | 플레이어 중심 **360도**, 반경 약 **2.2**, 범위 내 적에게 **1회 피해**, 스킬 속성 적용 |
| **Lv2** | 피해량 약 **+25%** |
| **Lv3** | 공격 범위 약 **+25%** |
| **Lv4** | 첫 회전 뒤 짧은 간격 후 **두 번째 회전 공격** 추가. 두 번째 공격 피해는 첫 공격의 약 **70%** |
| **Lv5** | 두 번째 회전 이후 **더 큰 마지막 충격파** 추가, 최종 공격 범위 증가 |

### 전투 역할

- 척준경이 적에게 둘러싸였을 때 다수를 동시에 정리하는 핵심 생존·광역 기술.
- 단순 피해 상승뿐 아니라 Lv4부터 공격 횟수, Lv5에서 마무리 충격파가 추가돼 성장 체감이 명확하다.

# 7. 일반 스킬 — 파성참(破城斬)

> 성벽을 가르듯 전방을 붕괴시키는 파괴형 참격.

| 레벨 | 효과 |
|---|---|
| **Lv1** | 전방을 크게 베어 범위 피해 |
| **Lv2** | 베기 범위와 피해 증가, 적중 시 경직 강화 |
| **Lv3** | 검기를 방출해 중거리까지 공격, **다단 히트** 추가 |
| **Lv4** | **방어구 파괴** 효과 추가, 강적의 슈퍼아머를 일부 해제하는 방향 |
| **Lv5** | 거대한 검기를 전방으로 방출해 넓은 범위를 초토화하고 적을 크게 밀어내는 최종형 |

### 전투 역할

- 파진이 “진입/돌파”를 담당한다면 파성참은 정면의 강적과 밀집된 적을 **힘으로 붕괴시키는 기술**이다.
- 일반 몹뿐 아니라 엘리트·보스 같은 강한 적에게도 척준경의 파괴력을 체감시키는 방향이다.

# 8. 일반 스킬 — 검풍

전방으로 관통하는 **검기 투사체**를 날리는 스킬.

| 레벨 | 효과 |
|---|---|
| **Lv1** | 전방으로 관통 검기 **1개** 발사, 속성 적용 |
| **Lv2** | 검기 크기 **+20%**, 속도 **+15%** |
| **Lv3** | 피해량 **+20%**, 관통 가능 대상 수 증가 |
| **Lv4** | 검기 **2개**를 좌우로 분산 발사 |
| **Lv5** | 검기 **3개**를 중앙 + 좌 + 우로 발사 |

### 구현 메모

- 기존 `StraightProjectile` 재사용을 우선한다.
- 속성 적용이 가능해야 한다.
- 척준경에게 최소한의 중거리 대응 수단을 주지만, 주몽과 역할이 겹칠 수 있어 **P1/후순위 스킬**로 분류됐다.

# 9. 일반 스킬 — 혈로

일정 시간 동안 이동 속도가 빨라지고, 이동 중 주변의 적을 지속적으로 베는 **이동형 자동 참격 버프**.

| 레벨 | 효과 |
|---|---|
| **Lv1** | 약 **4초** 지속. 이동속도 **+25%**. 약 **0.6초마다** 반경 약 **1.4**의 주변 참격. 스킬 속성 적용 |
| **Lv2** | 지속시간 **+1초** |
| **Lv3** | 이동속도 증가량을 **+35%**로 강화, 참격 범위 **+15%** |
| **Lv4** | 자동 참격 간격을 약 **0.4초**로 단축 |
| **Lv5** | 효과 종료 시 큰 **360도 마무리 참격** 추가 |

### 구현 주의

- 효과 종료 후 이동속도는 반드시 원래 값으로 복구한다.
- 중복 발동으로 이동속도나 타이머가 중첩되지 않게 한다.
- 척준경이 적 무리 속을 직접 통과하면서 적을 쓸어버리는 무쌍형 플레이를 가장 직접적으로 표현하는 스킬이다.

# 10. R 필살기 — 일기당천

## 최종 구현 프롬프트 기준

`일기당천`은 척준경이 순간적으로 한 번 베고 끝나는 기술이 아니라, **약 6초 동안 폭주 상태로 전투하는 R 필살기**다.

- 입력: **R 키**
- 형태: **시간 제한 폭주형 필살기**
- 지속시간: **약 6초**
- 쿨타임: **약 60초**
- 목적: 척준경의 핵심 판타지인 “혼자 적진을 뚫고 수많은 적을 베어내는 무쌍”을 짧은 시간 동안 극대화
- 일반 스킬과 별도의 캐릭터 고유 R 필살기로 취급

### 폭주 중 세부 효과

`IlgidangcheonBuff.cs`의 현재 직렬화 기본값과 전투 상태 적용 코드를 기준으로 다음 효과가 구현되어 있다.

- 지속시간: **6초**
- 이동속도: **×1.3**
- 기본공격 간격: **×0.45**
- 기본공격 사거리: **×1.35**
- 철혈참 잔상: **2타 활성화**
- 폭주 정상 종료 시: **반경 3.5 마무리 참격**

위 수치는 대화 복원 추정치가 아니라 현재 코드의 구현값이다. 실제 체감과 네트워크 동작은 별도의 Play Mode 검증 대상으로 남긴다.

### 이전 단발 참격안과의 관계

이전 복원 과정에서는 `일기당천`을 “짧은 선딜 뒤 전방 약 120도/4.5m를 한 번 베는 강력한 단발 참격”으로 정리했으나, 더 최신인 8월 9일 구현 프롬프트에서 **약 6초 폭주 + 약 60초 쿨타임**이 확인됐다.

따라서 문서 기준은 다음과 같이 정리한다.

- **최종 우선안:** 6초 폭주형 `일기당천`
- **폐기된 이전안:** 단발 전방 필살 참격
- 단발 참격의 카메라 흔들림·Hit Stop 같은 연출 아이디어는 폭주 시작/종료 연출에 재활용할 수 있으나, 이는 현재 확정 사항이 아니다.

### 구현 상태 기록

# 13. 문서 반영용 압축본

> **척준경**은 고려시대 무신 척준경을 2179년의 사이버펑크 세계관에 재해석한 근접 돌파형 영웅이다. 대형 사이버 장검을 사용하며, 적진에 직접 파고들어 광역 베기와 강한 일격으로 다수의 적을 쓸어버리는 무쌍형 전투를 담당한다. 기본공격은 전방 부채꼴 검격인 `철혈참`, 일반 스킬은 `파진`, `회천참`, `파성참`, `검풍`, `혈로` 5종이며 한 판에서는 최대 3종을 습득해 Lv1~Lv5까지 강화한다. 필살기 `일기당천`은 R키로 발동해 6초 동안 이동속도 ×1.3, 기본공격 간격 ×0.45, 기본공격 사거리 ×1.35와 철혈참 잔상 2타를 적용하고, 정상 종료 시 반경 3.5 마무리 참격을 발생시키는 폭주형 기술이다. 쿨타임은 약 60초다.
