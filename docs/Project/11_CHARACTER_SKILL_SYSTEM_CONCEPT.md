# 캐릭터·스킬 시스템 콘셉트

> 이 문서는 장기 설계 방향이다. 2026년 7월 31일 현재 실제 구현은 `HomingShotData`를 사용하는 유도 투사체형 기본공격 1개까지이며, 특수공격·속성·시너지·액티브·레벨업 선택은 아직 구현되지 않았다.

## 한 줄 소개

**여러 무기를 수집하는 일반적인 뱀서류와 달리, 캐릭터의 고유 무기 하나를 다양한 특수공격과 속성 조합으로 발전시키는 생존 액션 게임이다.**

## 1. 고유 무기와 특수공격

- 캐릭터마다 하나의 **고유 무기**를 사용한다.
- 다른 무기를 추가로 얻는 대신, 해당 무기의 여러 **특수공격**을 선택한다.
- 특수공격은 최대 3개까지 보유하며, 자동 쿨타임과 각 공격의 발동 조건에 따라 사용된다. *(개수 임시)*

### 예시: 활

- 기본공격: 전방으로 화살 발사
- 특수공격: 화살비, 거대 화살, 광역 화살

## 2. 캐릭터 고유 액티브

각 캐릭터는 고유한 **액티브 스킬 1개**를 가진다. 중요한 순간에 사용하는 필살기·궁극기 역할로, 캐릭터의 개성과 플레이 스타일을 결정한다.

## 3. 속성과 시너지

기본공격과 특수공격에는 불, 얼음, 충격, 바람 등의 속성이 부여될 수 있다. 코드 식별자 후보는 GDD의 `Burn`, `Freeze`, `Impact`, `Wind`를 기준으로 통일한다.

- 독 화살비
- 얼음 화살비
- 독 광역 화살

특정 속성들이 만나면 추가 효과가 발생한다. 부정적인 조합은 없으며, 모든 시너지는 플레이어에게 이득을 준다.

예시: **바람 + 화염 → 화염 강화 및 추가 피해**

## 4. 보조 아이템

아이템은 무기 공격을 보완하거나 일시적으로 전투 방식을 바꿔준다.

- 회오리 공격
- 중력장 생성
- 일정 시간 공격속도 제한 해제
- 관통 공격
- 체력 회복
- 공격 지점에 번개 발생

대부분의 아이템에도 무작위 속성이 부여되지만, 번개처럼 성격이 명확한 아이템은 속성이 고정될 수 있다. 캐릭터당 최대 5개까지 보유한다. *(개수 임시)*

## 5. 레벨업과 성장

레벨업 시 특정 구간에서는 **특수공격 또는 아이템**을 선택한다. 그 외 구간에서는 기본공격 강화, 공격력·체력·이동속도 등 캐릭터 능력치를 성장시킨다.

> **핵심 재미:** 하나의 고유 무기를 깊게 성장시키고, 특수공격·속성·아이템의 조합으로 매 판 새로운 빌드를 완성하는 것.

## 6. 현재 구현과 확장 규칙

현재 기본공격 흐름은 다음과 같다.

```text
PlayerAutoAttack
→ EnemyTargetFinder
→ SkillRunner.TryRun(SkillData, target)
→ Projectile
→ IDamageable.TakeDamage
```

- 데미지를 주는 스킬은 구체 `EnemyHealth`나 `PlayerHealth`를 직접 조작하지 않고 `IDamageable`을 통해 피해를 전달한다.
- 피해·쿨다운·사거리·투사체 속도와 프리팹은 `SkillData`에서 설정한다.
- 현재 `SkillRunner`는 프리팹 루트의 `Projectile`을 전제로 하므로 **투사체형 스킬에 한정된 실행기**다.
- 단순히 수치와 외형만 다른 유도 투사체는 새 `SkillData`와 프리팹 조합으로 만든다.
- 범위·근접·관통·장판·버프·회복형 스킬은 `Projectile`을 복사해 억지로 맞추지 않고 공통 실행 규격을 먼저 설계한다.
- 무작위 속성은 공격할 때마다 다시 뽑지 않는다. 기본공격은 게임 시작 시, 특수공격·아이템은 선택지가 만들어질 때 확정하고 해당 판 동안 유지한다.
- 스킬별 코드 안에 속성 조합을 직접 작성하지 않고 향후 `StatusEffectController`와 `SynergyResolver` 한 곳에서 판정한다.

현재 에셋:

| 항목 | 상태 |
|---|---|
| `HomingShotData.asset` | 구현 |
| `Projectile.prefab` | 구현 |
| 기본 스킬 4개 | 1개만 구현 |
| 특수공격·액티브 | 미구현 |
| 속성 데이터·상태 효과 | 미구현 |
| 플레이어 간 연계 2개 | 미구현 |
| 레벨업 선택·강화 적용 | 미구현 |
| 회복·자석 픽업 | 별도 필드 아이템으로 로컬 작업 중 |

## 7. 캐릭터 서사 표현

Shura는 전투 중 긴 대화나 컷신으로 캐릭터의 과거를 설명하지 않는다. 캐릭터 선택 또는 해금 화면에서 개인 서사를 짧게 제공하고, 고유 무기와 스킬 표현을 통해 성격과 과거가 드러나게 한다.

### 캐릭터 소개에 포함할 항목

| 항목 | 작성 내용 |
|---|---|
| 한 줄 소개 | 캐릭터의 정체성과 인상을 한 문장으로 요약 |
| 출신과 과거 | 어느 시대·장소에서 왔고 어떤 사건을 겪었는지 |
| 현재 목표 | 지금 싸우는 이유와 이루려는 것 |
| 고유 무기의 의미 | 캐릭터가 이 무기를 사용하는 개인적·상징적 이유 |
| 전투 성향 | 성격과 서사가 기본공격·특수공격·액티브에 어떻게 반영되는지 |
| 맵과의 연결 | 관련된 장소, 세력, 사건 또는 맵에 남아 있는 흔적 |

소개는 짧게 읽을 수 있게 작성하되, 맵의 배경 단서와 연결했을 때 더 큰 이야기를 추측할 수 있도록 한다. 실제 캐릭터별 설정은 세계관 연표와 맵 순서가 정해진 뒤 확정한다.
