## 7월 31일 기준 담당과 진행 상태

아래 담당은 기존 코드의 과거 작성자가 아니라 지금부터의 유지·확장 책임을 뜻한다.

| 담당자 | 담당 축 | 현재 상태 | 바로 이어서 할 일 |
|---|---|---|---|
| 진미리 | 게임 실행부터 멀티 방 참가와 게임 입장까지 | Relay와 네트워크 이동은 부분 구현. HUD·결과 패널은 원격 develop에 있으나 현재 맵 브랜치와 미통합 | HUD 수정 반영 → 현재 브랜치 통합 → 메뉴·방·게임 씬 연결 |
| 이재준 | 캐릭터·스킬·액티브·전투 성장 | `SkillData`, `SkillRunner`, 유도 투사체 기본공격 1개, 경험치·레벨 수치 구현 | 기본 스킬 4개 최소화, 레벨업 선택, 연계 2개 |
| 문성웅 | 맵·0~15분 라운드·적·종료·아이템 | 60초 스폰·3웨이브·임시 승패 흐름 구현. 회복·자석 아이템은 로컬 작업 중 | 아이템 검증·커밋 → 웨이브 설정 수정 → 전용 보스·15분 구조 |

상세한 완료·부분 구현·원격 반영·로컬 작업 구분은 `04_TECHNICAL_DESIGN.md`와 `12_CURRENT_PROJECT_STATUS.md`를 따른다.
