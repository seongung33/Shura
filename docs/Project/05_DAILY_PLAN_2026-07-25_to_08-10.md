## 날짜별 계획

### 7월 25일 — 프로젝트 기반

- Unity·GitHub 기본 구조 완료
- `main`, `develop`과 팀원 권한 확인
- 세 명 모두 같은 Unity 버전으로 Clone 테스트
- 기획·MVP·기술 문서 합의
- `Main.unity` 편집 담당자 지정

**종료 조건:** 다른 팀원의 PC에서 프로젝트가 오류 없이 열린다.

### 7월 26일 — 플레이어와 적 최소 구현

- 개발자 A: 플레이어 이동, 카메라, 체력
- 개발자 B: 적 추적, 접촉 피해, 적 체력
- 콘텐츠 담당: 임시 캐릭터·적·맵 에셋과 UI 와이어프레임
- 공동: 네트워크 후보 하나 선정 및 `NetworkTest` 시작

**종료 조건:** 플레이어가 이동하고 적에게 피해를 받는다.

### 7월 27일 — 네트워크 결정일

- 두 개발자 페어 작업으로 방 생성·참가
- 두 플레이어 위치 동기화
- 적 하나와 체력 동기화
- Windows 두 대 테스트
- Web 가능성 또는 로컬 2인 폴백 판단
- 결정 결과를 `08_DECISION_LOG.md`에 기록

**종료 조건:** 온라인 2인 유지 또는 로컬 2인 폴백을 확정한다.

### 7월 28일 — 기본 공격과 경험치

- 자동 공격
- 투사체와 피해
- 적 사망과 경험치 드롭
- 경험치 획득과 레벨업
- 기본 HUD

**종료 조건:** 적을 처치하고 레벨이 오른다.

### 7월 29일 — 스킬 데이터 구조

- `SkillData`, `CharacterData` 작성
- 스킬 2개 구현
- 레벨업 선택지와 스킬 강화
- Object Pool 최소 적용
- 콘텐츠 담당이 Unity에서 수치 입력

**종료 조건:** 코드 수정 없이 스킬 피해와 쿨다운을 조정할 수 있다.

### 7월 30일 — 첫 세로 슬라이스

- 적 생성과 시간 기반 웨이브
- 승리·패배·재시작
- 기본 사운드
- `develop` 통합
- Windows 첫 실행 빌드

**종료 조건:** 임시 그래픽으로도 한 판이 시작되고 끝난다.

### 7월 31일 — 연계 시스템 1

- 상태 효과 태그 기록
- `SynergyResolver` 구현
- `Freeze + Impact` 분쇄 반응
- 연계 팝업과 시각 효과

**종료 조건:** 서로 다른 플레이어의 공격으로 분쇄가 발동한다.

### 8월 1일 — 연계 시스템 2

- `Burn + Wind` 화염 폭풍
- 연계 내부 쿨다운
- 멀티플레이 환경에서 결과 동기화

**종료 조건:** 연계 2개가 반복 테스트에서 안정적으로 발동한다.

### 8월 2일 — 멀티플레이 통합

### 8월 3일 — 협동 핵심 마감

**종료 조건:** 제3자가 플레이해도 협동과 연계의 차이를 이해한다.

### 8월 4일 — 적과 보스

### 8월 5일 — Web 빌드 조기 확정

### 8월 6일 — UI·아트·사운드 정리

### 8월 7일 — 기능 동결
