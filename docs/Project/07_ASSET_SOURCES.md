# Shura 외부 에셋 및 오픈소스 출처

## 기록 규칙

- 외부 파일을 프로젝트에 추가한 당일 기록한다.
- 무료라는 설명만 믿지 않고 정확한 라이선스 페이지를 확인한다.
- 수정했더라도 원작자와 원본 출처를 기록한다.
- 출처를 찾을 수 없는 이미지·음원·폰트는 사용하지 않는다.
- AI 생성 에셋은 사용 도구와 프롬프트, 사람이 수정한 내용을 함께 기록한다.
- Asset Store 패키지는 패키지 이름, 제작자, URL, 라이선스 형태를 기록한다.

## 사용 전 라이선스 확인표

- [ ] 상업적 사용이 가능한가?
- [ ] 수정이 가능한가?
- [ ] 저작자 표시가 필요한가?
- [ ] 재배포 조건이 있는가?
- [ ] 원본 파일을 저장소에 포함해도 되는가?
- [ ] Steam 출시에서도 같은 조건으로 사용할 수 있는가?
- [ ] 라이선스 페이지를 PDF 작성 시 다시 찾을 수 있는가?

## 금지 대상

- 출처가 없는 커뮤니티 재업로드 파일
- 검색 결과에서 직접 저장한 이미지
- 다른 게임의 스프라이트·음원 추출물
- 상업적 이용이 금지된 폰트·음원
- 라이선스가 불명확한 AI 모델 또는 에셋
- 구매 계정 외 팀원이 사용할 수 없는 유료 에셋의 무단 공유
