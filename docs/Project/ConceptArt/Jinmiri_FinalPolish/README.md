# 진미리 최종 폴리시 콘셉트

2026-08-10 생성한 픽셀 변환용 적 디자인 시안이다. 기존 게임 에셋을 바로 교체하지 않고 검토·변환용 원본으로 보관한다.

## 파일

- `enemy_archetypes_and_elite_concept.png`: 일반, 빠른, 탱커, 엘리트 순서의 역할 구분 시트
- `jangsanbeom_revised_concept.png`: 장산범 보스 개선 시안
- `PixelConversions/`: 진미리가 변환한 장산범 및 적 4종 픽셀 원본
- `PixelConversions/jangsan_forest_floor_pixel.png`: 실제 게임에 연결한 장산 숲 픽셀 배경 원본

## 픽셀 변환 기준

- 일반·빠른·탱커: 기존 4프레임 가로 워크 시트와 같은 규격으로 제작한다.
- 엘리트: 청록 도깨비불, 붉은 천, 월도 실루엣을 반드시 남긴다.
- 장산범: 흰 장모, 붉은 눈, 얼굴의 미소, 방울·부적, 어깨의 초승달 문양을 남긴다.
- 축소 후에도 역할이 읽히도록 작은 갑옷 문양보다 큰 실루엣과 색상 포인트를 우선한다.
- Unity 적용 전 원본 파일을 덮어쓰지 말고 새 파일과 `.meta`를 함께 추가한다.

## AI 사용·출처 기록

- 도구: OpenAI ImageGen 내장 이미지 생성
- 목적: 일반몹 3종, 신규 엘리트, 장산범 최종 디자인 시안 제작
- 입력: 저장소의 기존 적 3종 및 장산범 이미지와 역할·색상·실루엣 제약
- 산출물: 이 폴더의 PNG 2개
- 사람 검토: 기존 에셋과 비교해 가독성, 한국 설화 톤, 픽셀 변환 기준을 검토했다.
- 적용 상태: 콘셉트만 추가했으며 게임 런타임 에셋과 프리팹은 변경하지 않았다.
- 2026-08-10 추가 적용: 진미리가 픽셀 변환한 장산 숲 배경, 무궁화 개화 로고 인트로, 설화 팔레트 UI를 런타임에 연결했다. 적·보스 픽셀 변환본은 배경 제거·프레임 분리 전 원본으로 보존한다.
- 사용 범위: Team Shura 프로젝트 내부 제작·제출용
