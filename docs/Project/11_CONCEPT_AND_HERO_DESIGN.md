## 1. 확정 콘셉트

> 한국의 역사·신화를 먼 미래의 사이버펑크 세계에 결합한, 무겁고 어두운 분위기의 협동 뱀서라이크.

- 시대 배경: **2179년**, 디스토피아
- 전통 복식·무기·문양·신화적 특징은 유지하고 외형·장비를 미래적으로 재해석
- 분위기 참고: 《산나비》(한국적 사이버펑크), 《데드셀》(배경·상호작용으로 서사 전달)
- 스토리는 보조 요소. 해커톤에서는 배경 디자인, 짧은 대사("여기는 어디지?"), 2179년 연도 노출 정도로만 표현

### 세계관 요약

- 과거의 강자들이 정체불명의 힘에 의해 2179년으로 강제 소환됨
- 플레이어 캐릭터: 역사 인물 + 신화·전설 인물 + 가상의 과거/미래 인물 혼용 가능
- 스토리 후보: 미래 침략 세력(마족·외계인 등)에 맞서는 소환 / 투기장 설정
- 몬스터·보스: 한국 요괴 재해석 — 어둑시니, 두억시니, 구미호, 창귀, 손각시, 장산범 (역할 미정)

## 2. 해커톤 범위 (회의 결정 우선)

| 항목 | 기준 |
|---|---|

| 영웅 | 2명 제작 (1호: 주몽, 2호: 미정) |

| 맵 | 1개 |

| 외부 성장 | 필수 아님, 여유 시 구현 |

## 3. 속성 시스템 (2026-07-29 확정)

- 속성은 **7종**: `독` `물` `번개` `얼음` `흙` `바람` `불`
  - ※ 회의 시점의 5속성(불·물·바람·흙·풀)안을 대체함
- 게임 시작 시 플레이어는 **무속성**
- 스킬 습득 시 속성이 **랜덤으로 부여**됨 → 같은 스킬도 판마다 속성이 달라짐 (반복 플레이 가치)

### 연계(시너지) 규칙

- 서로 다른 플레이어의 속성 효과가 조합되면 연계 반응 발동
- **특정 조합만 반응**한다. 상성이 맞지 않는 조합(예: 물+불)은 반응이 없을 뿐, **디버프는 주지 않는다**
- **동속성 중첩은 무반응** (증폭 없음) — 2026-07-30 확정
- **랜덤 속성 보정**: 스킬 선택지에 부여될 속성을 미리 표시한다 → 플레이어가 연계를 노리고 선택 가능 — 2026-07-30 확정

### 해커톤 연계 조합표 (2026-07-30 확정)

7속성 전부가 최소 1회 등장하도록 4개 조합을 선정했다. 세부 수치(피해량·범위·지속시간)는 미정.

| 조합 | 반응명 | 효과 | 유형 |
|---|---|---|---|
| 물+번개 | 감전 | 주변 적에게 연쇄 전이 피해 | 연쇄 |
| 독+흙 | 독늪 | 지속 피해 + 감속 장판 | 장판 |
| 불+바람 | 화염 폭풍 | 화염 범위 확대 + 지속 피해 | 확산 |
| 얼음+흙 | 분쇄 | 대상 주변 범위 피해 | 폭발 |

나머지 조합(감전·독늪 등 이전 초안 포함)은 해커톤 이후 확장 후보로 보류한다.

## 4. 성장 구조

### 레벨업 (일반)

- 레벨업 시 **기본 능력치 3택1** 선택지 제공
- 선택지 예시: 공격 속도 증가, 투사체 속도 증가, 이동 속도 증가 등

### 스킬 습득 (2026-07-30 확정)

- **특정 레벨 도달 시 스킬 3택1** 선택지가 등장한다 (일반 레벨업의 능력치 3택1과 별개)
- 선택지에는 습득 시 부여될 **랜덤 속성을 미리 표시**한다
- 스킬은 **캐릭터 전용** — 영웅마다 자기 스킬 세트만 배운다
- 어느 레벨에서 스킬 선택지가 나오는지(예: 3/6/9)는 미정

### 스킬 설계 시 필수 정의 항목

각 스킬은 이름·속성만이 아니라 다음을 구체적으로 설계한다.

- 공격 방식 / 발동 방향 / 적 탐색 방식 / 공격 범위
- 다른 스킬과의 연계
- 레벨업 시 강화 내용 (범위, 피해량, 쿨다운, 효과, 이펙트)
- 최대 레벨 도달 시 연출 (확실한 성장 체감)

## 5. 영웅 1호: 주몽

- 모티프: 고구려 시조, 백발백중의 신궁 → 사이버펑크 재해석 (외형 디자인 미정)
- 역할: 원거리 궁수

### 기본공격 (자동 발동)

- 시작 시점: **유도 기능 없는 단발 화살**
  - ※ 현재 구현된 유도 투사체는 주몽 기본공격에는 사용하지 않음
- 레벨업으로 선택 획득 가능한 기본공격 강화:
  - **직선 관통 화살**: 일직선상의 적 관통
  - **차지형 화살**: 모아서 쏘는 강화 한 방
- 발사 방향: **마지막 이동 방향** — 2026-07-30 확정 (이동으로 조준하는 방식)

### 전용 스킬 (2026-07-29 확정)

모든 스킬은 습득 시 속성이 랜덤 부여되며, "숙련도"는 스킬 레벨과 동일한 개념이다(같은 스킬 재선택으로 상승).

| # | 스킬 | 설명 | 우선순위 |
|---|---|---|---|
| 1 | **원소 폭발 화살** | 명중 시 부여된 속성으로 폭발(범위 피해 + 속성 적용). 연계 트리거 핵심 | P0 |
| 2 | **편전** | 매우 빠른 관통 화살. 스킬 레벨이 오를수록 관통 가능 몹 수 증가 | P0 |
| 3 | **적토마** | 이동 속도 증가 + 밟은 적에게 피해 + 지나간 자리에 일정 시간 원소 장판 | P0 |
| 4 | **궁사의 패러독스** | 화살이 물고기처럼 좌우로 흔들리며 전진. 지나간 자리에 원소 장판. 맵 끝까지 비행, 투사체 속도 느림 | P1 |
| 5 | **화살비틀기** | 활 시위를 비틀어 발사. 스킬 레벨이 오를수록 원에 가까워지는 곡선 경로. 경로상 적 무조건 관통 + 경로에 원소 장판 | P1 |

### 필살기: 화살비

- 다수의 화살이 범위에 낙하하는 광역기 (일반 스킬에서 필살기로 승격)
- 쿨타임 15초~2분 범위에서 검토, 상세 수치·연출 미정

### 공용 구현 시스템

- **원소 장판(트레일)**: 적토마·궁사의 패러독스·화살비틀기가 공유 — 한 번 구현해 재사용
- **관통 판정**: 편전·화살비틀기 공유
- 장판·폭발은 해당 스킬의 랜덤 속성으로 발동 → 연계 반응의 조건 생성 수단
