# 무궁(MUGUNG) — 게임 소개 및 설명

> 한국의 영웅과 설화를 2179년 사이버펑크 세계에서 재해석한 2D 탑다운 협동 생존 액션 게임

## 1. 게임 개요

| 항목 | 내용 |
|---|---|
| 게임명 | 무궁(MUGUNG) |
| 장르 | 2D 탑다운 협동 생존 액션 |
| 엔진 | Unity 6.3 LTS |
| 플랫폼 | Web(최종 배포 준비 중) |
| 플레이 인원 | 싱글 플레이 또는 온라인 2인 협동 |
| 한 판의 목표 | 15분 동안 몰려오는 적을 상대하고 최종 보스 장산범 처치 |
| 핵심 소재 | 한국사 영웅, 한국 설화, 사이버펑크 |

2179년, 설화 속 재앙이 미래 도시를 뒤덮는다. 플레이어는 주몽 또는 척준경을 선택해 적의 파도를 돌파하고, 동료와 속성 효과를 연계하며 마지막에 등장하는 장산범을 쓰러뜨려야 한다.

무궁은 짧은 시간에도 이해할 수 있는 자동 공격과 생존 액션을 기반으로 한다. 동시에 영웅별 필살기, 팀 경험치, 레벨업 선택, 역할이 다른 적과 보스를 더해 협동 판단의 재미를 만든다.

## 2. 핵심 특징

### 서로 다른 두 영웅

- **주몽:** 빠른 화살과 투사체 공격으로 거리를 유지하는 원거리 영웅
- **척준경:** 적진을 돌파하고 가까운 적을 베어내는 근거리 영웅

두 영웅은 공격 거리와 위험 관리 방식이 다르다. 멀티플레이에서는 각자의 강점을 살려 전열과 후방을 나누는 것이 중요하다.

### 15분 생존과 장산범 보스전

시간이 지날수록 적의 수와 종류가 변화한다. 적을 처치해 팀 경험치를 모으고 능력을 강화한 뒤, 15분에 일반 웨이브가 보스전으로 전환되면 장산범을 처치해야 승리한다.

### 팀 단위 성장

적이 떨어뜨린 경험치를 모으면 팀 레벨이 오른다. 레벨업 때 제시되는 강화 중 하나를 선택해 피해량, 투사체 속도, 공격 주기 등 전투 능력을 성장시킨다.

### 온라인 2인 협동

호스트가 Relay 방을 만들면 6자리 참가 코드가 생성된다. 다른 플레이어가 코드를 입력해 참가하고, 두 명이 영웅을 선택하면 함께 전투를 시작한다.

## 3. 조작 방법

| 입력 | 기능 |
|---|---|
| `WASD` 또는 방향키 | 이동 |
| `R` | 선택한 영웅의 필살기 |
| `F1` | 조작 도움말 열기·닫기 |
| `Esc` 또는 우측 상단 메뉴 | 일시정지·게임 메뉴 |
| 마우스 | 메뉴·캐릭터·레벨업 강화 선택 |

기본 공격은 자동으로 발동한다. 플레이어는 적과 거리를 조절하고 경험치를 회수하며, 위험한 순간에 필살기와 레벨업 강화를 활용한다.

## 4. 플레이 방법

### 싱글 플레이

1. 첫 화면의 로고 연출이 끝나면 **싱글 플레이**를 선택한다.
2. 주몽 또는 척준경을 선택하고 **게임 시작**을 누른다.
3. 이동으로 적을 피하면서 자동 공격으로 적을 처치한다.
4. 경험치를 모아 레벨업하고 원하는 강화를 선택한다.
5. 15분에 등장하는 장산범을 처치하면 승리한다.

### 멀티 플레이

1. 메인 메뉴에서 **멀티 플레이**를 선택한다.
2. 한 명이 **방 만들기**를 눌러 참가 코드를 생성한다.
3. 다른 한 명은 전달받은 코드를 입력하고 **방 참가**를 누른다.
4. 두 플레이어가 로비에서 영웅을 선택한다.
5. 인원이 모두 연결되면 호스트가 게임을 시작한다.
6. 서로의 위치와 역할을 맞추며 경험치와 레벨업 효과를 공유한다.
7. 종료 후 로비나 메인 메뉴로 돌아갈 수 있다.

## 5. Web 실행 방법

### 플레이어

1. 최종 플레이 주소 **[Web 플레이 URL 입력]** 을 데스크톱 브라우저에서 연다.
2. 로딩이 끝나면 게임 화면을 한 번 클릭해 키보드 입력과 오디오를 활성화한다.
3. 화면이 작으면 브라우저 전체 화면을 사용한다.
4. 멀티플레이는 서로 다른 브라우저 또는 기기에서 같은 참가 코드로 접속한다.

최신 Chrome·Edge 계열 브라우저와 하드웨어 가속 사용을 권장한다. 모바일 브라우저는 제출 검증 대상이 아니다.

### 개발·심사용 로컬 실행

1. 저장소 **[GitHub URL 입력]** 를 내려받는다.
2. Unity Hub에서 Unity 6.3 LTS 프로젝트로 연다.
3. `Assets/_Project/Scenes/MainMenu.unity`를 연다.
4. Play 버튼을 눌러 실행한다.
5. Web 빌드는 Unity의 Build Profiles에서 Web 플랫폼과 Scene List를 확인한 뒤 빌드한다.

## 6. 제출 시점 검증 상태

- 기존 검증 기록: Windows Editor와 실행 파일을 이용한 2인 Relay 접속·전투·패배·복귀
- 최종 확인 예정: 공개 Web 주소, Web 2인 Relay, 싱글 15분 완주와 장산범 승리, 최신 메뉴 경로의 퇴장·재입장
