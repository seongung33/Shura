## PDF 제작 전 필수 교체 항목

- [ ] 최종 Web 플레이 주소
- [ ] GitHub 저장소 및 제출 브랜치·릴리스 주소
- [ ] 시연 영상 주소
- [ ] 팀명과 팀원 연락처(요구되는 경우에만)
- [ ] 메인 메뉴, 싱글 전투, 레벨업, 보스전, 멀티 로비 캡처
- [ ] Web 빌드와 실제 2인 Relay 최종 검증 결과
- [ ] 대회가 요구하는 페이지 수·파일명·용량 확인

## 현재 상태 표기 원칙

- 코드와 에셋이 저장소에 있으면 **구현**으로 표기한다.
- 사람이 Play Mode·빌드에서 확인한 항목만 **검증 완료**로 표기한다.
- 아직 확인하지 않은 Web·15분 완주·최신 2인 흐름은 **최종 검증 예정**으로 표기한다.
- 참고 작품은 영감의 출처로, 실제 포함 에셋은 라이선스 출처로 구분한다.
