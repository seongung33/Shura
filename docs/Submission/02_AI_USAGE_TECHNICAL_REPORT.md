# 무궁(MUGUNG) — AI 활용 기술 문서

## 1. 활용 목적

무궁 팀은 짧은 개발 기간에 기능 구현, 시각 시안 제작, 반복 검증과 문서화를 병행하기 위해 생성형 AI를 보조 도구로 활용했다. AI 결과를 그대로 제출하지 않고, 팀원이 프로젝트 구조와 게임 방향에 맞게 선택·수정·통합한 뒤 Unity와 Git 이력으로 검증하는 것을 원칙으로 삼았다.

## 3. 주요 활용 내역

### 코드와 시스템

- 싱글·Relay 2인 입장 흐름과 네트워크 소유권 점검
- 주몽·척준경 선택 및 공격 판정 오류 진단
- 자동 공격, 경험치, 레벨업 선택, 필살기와 전투 피드백 구현 보조
- 15분 웨이브, 적 3종, 엘리트와 장산범 보스 연결
- 메인 메뉴, HUD, 결과·설정·도움말 UI의 가독성과 흐름 개선
- 씬 YAML 동시 편집을 줄이기 위한 런타임 UI 생성 방식 검토

### 그래픽과 연출

- 한국 설화와 사이버펑크를 결합한 미래 도시 배경 시안
- 적청 무궁화 문양과 한글 `무궁` 로고 시안 및 픽셀 변환
- 일반 적 3종과 장산범의 역할별 실루엣·워크 프레임 시안
- 영웅 필살기 컷인, 대사, 화면 정지·플래시·카메라 흔들림 연출안

### 문서와 품질 관리

- 구현 상태와 실행 검증 상태를 분리한 프로젝트 문서 갱신
- 에셋 출처·라이선스·AI 생성 및 후처리 내역 기록
- PR 단위 변경 범위, 회귀 테스트 항목과 제출 체크리스트 작성

## 4. 대표 요청 요약

아래 내용은 실제 작업에서 반복 사용한 요청의 목적과 제약을 재구성한 요약이며, 원문 프롬프트의 완전한 전사는 아니다.

### 멀티 캐릭터 오류 진단

> 최신 develop과 네트워크 캐릭터 계약을 먼저 확인한다. 멀티에서 척준경이 선택되지 않거나 근접 공격 피해가 0이 되는 원인을 찾고, 서버 권한과 싱글 동작을 깨뜨리지 않는 최소 수정 및 검증 방법을 제시한다.

### 적 워크 애니메이션 제작

> 한국 설화와 2179년 사이버펑크 분위기를 유지한 일반 적을 역할별로 구분한다. 작은 게임 화면에서도 실루엣이 읽히도록 하고, 같은 크기와 기준선의 4프레임 가로 워크 시트로 제작한다.

### 시작 화면 연출

> 한글 픽셀 `무궁` 로고가 꽃의 중심에서 개화하는 느낌으로 등장하고 메뉴가 자연스럽게 이어지게 한다. 공용 씬 파일 충돌을 피하고 기존 버튼 동작과 입력 생략 기능은 유지한다.

### 필살기 피드백

> 주몽과 척준경의 성격이 드러나는 짧은 대사, 컷인, 화면 플래시와 타격 강조를 설계한다. 네트워크에서 피해나 오디오가 중복되지 않도록 시각 연출과 서버 판정을 분리한다.

### 문서 감사

> 전체 문서와 최신 코드를 비교하고, 구현된 기능·실행 검증된 기능·최종 검증이 필요한 기능을 구분한다. 오래된 설명은 최신 상태로 고치되 미검증 항목을 완료로 과장하지 않는다.

## 5. AI 결과 검증 절차

1. 작업 전 `develop`을 최신화하고 기존 문서·코드 계약을 읽는다.
2. AI 제안 중 현재 담당 범위와 충돌 가능성이 없는 방식을 선택한다.
3. 기능별 브랜치에서 작은 변경으로 구현한다.
4. 컴파일, 자동 검증기, 씬·프리팹 참조와 에셋 임포트를 확인한다.
5. Unity Play Mode 또는 빌드에서 사람이 실제 동작과 가독성을 확인한다.
6. 변경 파일과 테스트 결과를 PR에 기록하고 리뷰 후 `develop`에 병합한다.
7. 미확인 항목은 문서에서 ‘검증 필요’로 남긴다.

## 6. 한계와 대응

| 위험 | 대응 |
|---|---|
| AI가 존재하지 않는 API·오브젝트를 가정 | 저장소 검색과 Unity 컴파일로 확인 |
| 씬·프리팹 텍스트 변경으로 충돌 발생 | 런타임 구성, 전용 테스트 씬, 담당자 분리 사용 |
| 이미지의 배경·프레임·해상도가 게임에 부적합 | 투명화, Point 필터, 동일 셀 크기와 실제 화면 검수 |
| 기능 구현과 실제 실행 검증을 혼동 | 문서와 PR에서 구현·자동 점검·수동 점검을 분리 |
| AI 생성물의 출처가 불명확 | 생성 도구·날짜·프롬프트 요약·후처리·사용 위치 기록 |

## 7. 사람의 기여와 책임

게임의 콘셉트, 재미의 기준, 캐릭터 역할, 최종 UI 선택과 제출 범위는 팀이 결정했다. 팀원은 AI가 만든 초안을 기존 코드에 맞게 수정하고, Unity 컴포넌트·프리팹·씬·네트워크 권한을 연결했으며, 결과물을 직접 플레이하고 Git 리뷰로 승인했다. 따라서 AI는 제작 속도를 높인 보조 도구이고 최종 설계·통합·품질 책임은 팀에 있다.
