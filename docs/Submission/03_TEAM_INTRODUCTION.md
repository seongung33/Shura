# 무궁(MUGUNG) — 팀 소개

## 1. 팀 목표

무궁 팀은 한국사 영웅과 설화를 미래적으로 재해석한 2인 협동 생존 액션을 완성하는 것을 목표로 했다. 세 명이 게임 진입·영웅 전투·스테이지 진행을 나누어 개발하고, 공통 계약과 PR 리뷰를 통해 하나의 플레이 흐름으로 통합했다.

## 2. 팀원별 역할

### 진미리 — 게임 진입·멀티플레이·전체 통합

- 메인 메뉴, 싱글·멀티 진입과 영웅 선택 UX
- Unity Multiplayer Services/Relay 방 생성·참가·퇴장 흐름
- 네트워크 플레이어 생성, 소유권과 서버 전투 판정 통합
- HUD, 설정, 도움말, 결과 화면과 메인 메뉴 비주얼 폴리시
- 로고·배경·적 애니메이션·사운드 등 생성형 AI 에셋 후처리 및 연결
- Main 씬, Web 빌드 준비, 제출 문서와 최종 통합 검증

### 이재준 — 캐릭터·스킬·전투 성장

- 주몽·척준경 캐릭터 설계와 전투 구현
- 기본 공격, 액티브 스킬과 영웅별 필살기
- 스킬 데이터와 공통 피해 인터페이스
- 경험치·레벨업 선택과 능력 강화
- 속성 효과와 협동 연계 규칙
- 캐릭터·스킬 단위 테스트와 밸런스 조정

### 문성웅 — 맵·라운드·적·아이템·게임 종료

- 15분 라운드 타이머와 구간별 웨이브
- 일반 적, 엘리트와 장산범 보스
- 맵 구성과 적 생성·추적·접촉 공격
- 회복·자석 등 필드 아이템
- 보스 전환, 승리·패배와 재시작 흐름
- 스테이지 데이터와 성능·밀도 조정

## 3. 협업 방식

| 원칙 | 적용 방식 |
|---|---|
| 최신 코드에서 시작 | 작업 전 `develop`을 최신화하고 새 기능 브랜치 생성 |
| 충돌 방지 | Main 씬과 공용 프리팹 담당자를 구분하고 가능하면 코드·데이터 단위로 전달 |
| 작은 PR | 기능, 오류 수정, 문서를 분리해 리뷰 가능한 크기로 병합 |
| 계약 기반 통합 | `IDamageable`, 플레이어 체력·사망, 네트워크 소유권 등 공용 인터페이스 유지 |
| 검증 기록 | 자동 점검과 Play Mode·빌드 수동 확인을 구분해 문서화 |
| AI 책임 사용 | AI 초안을 팀원이 검토·후처리·테스트하고 출처와 활용 내역 기록 |

## 4. 역할 간 연결

- 진미리가 생성한 플레이어에 이재준의 캐릭터·스킬 구성이 적용되고 문성웅의 라운드에 등록된다.
- 이재준의 공격은 공통 피해 계약을 통해 문성웅의 일반 적과 장산범에 피해를 준다.
- 문성웅의 적과 아이템이 만든 경험·회복 흐름은 이재준의 성장 시스템과 HUD에 반영된다.
- 진미리는 이 흐름을 싱글과 Relay 멀티 양쪽에서 연결하고 최종 빌드에서 검증한다.

## 5. 팀이 해결한 주요 과제

- 서로 다른 공격 구조를 가진 두 영웅을 싱글과 네트워크 환경에 함께 적용
- 15분 웨이브, 팀 성장과 보스전을 하나의 완결된 런으로 구성
- 서버 권한 전투와 클라이언트 UI·연출을 분리해 중복 피해를 방지
- AI 이미지 시안을 실제 픽셀 게임용 투명 에셋과 워크 시트로 후처리
- 동시 개발 중 씬·프리팹 충돌을 줄이기 위한 브랜치·PR·통합 규칙 운영
